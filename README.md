# Cadastro de Clientes - Imobiliária

## 📌 Descrição

Este projeto é um sistema de **cadastro de clientes para uma imobiliária**.
Utilizando operações **CRUD (Create, Read, Update, Delete)**.

O sistema possui uma interface web básica e se conecta a um banco de dados para salvar e consultar os registros.

---

## ⚙️ Tecnologias Utilizadas

* **Python** – (lógica e backend)
* **MySQL** – (banco de dados)
* **HTML e CSS** – (interface básica)


---

## 📋 Funcionalidades

* ➕ **Cadastrar clientes**
* 📄 **Visualizar clientes cadastrados**
* ✏️ **Editar informações de clientes**
* ❌ **Excluir clientes**

Todas as operações seguem o padrão **CRUD**.

---

## 👥 Clientes de Exemplo

O banco de dados inicial já contém **3 clientes cadastrados para demonstração**:

* João
* Mariana
* Ricardo

Esses registros podem ser editados ou removidos no sistema.

---

## 🗄️ Configuração do Banco de Dados

1. Abrir o **MySQL Workbench**
2. Criar um **schema** chamado:

```
imobiliaria
```

3. Importar o banco de dados que está na pasta:

```
dbImobiliaria
```

---

## ▶️ Como Executar o Projeto

1. Abrir o **Prompt de Comando (CMD)**

2. Ir até o diretório da pasta do projeto:

```
CadastroDeClientes
```

3. Ativar o ambiente virtual:

```
venv\Scripts\activate.bat
```

4. Executar a aplicação:

```
py app.py
```

5. Abrir o navegador no endereço:

```
http://127.0.0.1:5000
```
